## Bugs found / fixed
- **Cloud lead report gating**: waits for the whole handoff set before its one turn (parity with local's outstanding set), with a 5-minute straggler cap.
- **Take-control asks on cloud never notified**: prompt told the model to write "press Take control" as text; and for Claude-CLI turns the tool runs on the desk (mcp-sub8), so the Worker-side hook never fired. Attention is now recorded from the relay's tool event.
- **One-job policy vs reminders**: reminders (`once` triggers) are excluded from merge/overlap/solo logic; a new cadence replaces a merged row's stale triggers. Tool text/rejection message point "remind me…" at `once_at`.
- **Mid-turn subprocess writes were clobbered** by runUserTurn's emit callback (`upsertBot(bot)` per message event) — now a field-level patchBot. Root cause of every "created but not on the record" routine/reminder this evening.
- **One-off reminders** did not exist (and the model fabricated "Set"): added `once` triggers (`once_at`), classifier bypass when a trigger is explicit, auto-disable after firing.
- **Claude Code built-in tools leaking on desks**: RemoteTrigger/Cron*/ScheduleWakeup/Monitor/PushNotification now disallowed alongside SendMessage/ListAgents, for local AND cloud desk turns (`DESK_DISALLOWED_TOOLS`).
- **Memory writes landed outside the digest's directory** (`<root>/profile.md` vs advertised `<root>/memory/profile.md`) — relative memory paths now resolve inside `memory/`.
- **Removed teammates leaked their X display + Chrome** in the shared container (pids/memory never returned). `vm.stopDisplay(container, n)` now runs on all three delete paths (DELETE /api/bots/:id, remove_teammate in mcp-sub8 and agent).
