<h1 align="center">Sub8</h1>

<p align="center">
  Local desktop assistants that live on their own Linux computers.
</p>

<p align="center">
  <a href="https://github.com/sub8bot/Sub8/releases/latest"><img src="https://img.shields.io/github/v/release/sub8bot/Sub8" alt="Latest release"></a>
  <a href="https://github.com/sub8bot/Sub8/blob/master/LICENSE"><img src="https://img.shields.io/badge/license-BSL%201.1-blue" alt="Business Source License 1.1"></a>
</p>

Each bot gets an isolated Linux desktop. You talk in the chat. It clicks, types, and works there — never on your machine.

## Install

[Releases](https://github.com/sub8bot/Sub8/releases/latest) · [sub8.bot](https://sub8.bot)

| | |
|---|---|
| macOS Apple Silicon | [Sub8-mac-arm64.dmg](https://github.com/sub8bot/Sub8/releases/latest/download/Sub8-mac-arm64.dmg) |
| macOS Intel | [Sub8-mac-x64.dmg](https://github.com/sub8bot/Sub8/releases/latest/download/Sub8-mac-x64.dmg) |
| Windows | [Sub8-win-x64.exe](https://github.com/sub8bot/Sub8/releases/latest/download/Sub8-win-x64.exe) |
| Linux | [Sub8-linux-x86_64.AppImage](https://github.com/sub8bot/Sub8/releases/latest/download/Sub8-linux-x86_64.AppImage) |

Docker or Colima is required so each bot can have a computer.

```bash
npm install
./start.sh
```
